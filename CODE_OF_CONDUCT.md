# Code of Conduct

## Hamara Vaada

Hum ek open aur welcoming environment banaye rakhne ke liye committed hain, chahe experience level, background, ya identity kuch bhi ho.

## Expected Behaviour

- Respectful aur constructive language use karein.
- Doosron ke viewpoints aur experiences ko accept karein.
- Beginners ke sawalon ka patiently jawab dein.

## Unacceptable Behaviour

- Harassment, insults, ya personal attacks.
- Trolling ya offensive comments.
- Kisi bhi tarah ka discrimination.

## Reporting

Agar koi issue face karein, to repository maintainer se ek issue ya private message ke through contact karein.
