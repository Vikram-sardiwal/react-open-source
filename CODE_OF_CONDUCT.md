# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, inclusive, and respectful environment for everyone who participates in this project, regardless of their experience level, background, identity, or skill set.

Our goal is to create a community where everyone feels comfortable learning, contributing, asking questions, sharing ideas, and collaborating with others.

## Expected Behavior

All contributors and community members are expected to:

* Use respectful, professional, and constructive language.
* Treat everyone with kindness, patience, and respect.
* Be open to different opinions, perspectives, and experiences.
* Provide constructive and helpful feedback.
* Support beginners and help them learn without judgment.
* Focus on the project and ideas rather than individuals.
* Follow the project's contribution guidelines and community standards.

## Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment, intimidation, or personal attacks.
* Insulting, threatening, or deliberately disrespectful comments.
* Trolling or intentionally disruptive behavior.
* Discriminatory or hateful language or behavior.
* Unwanted sexual or inappropriate content.
* Publishing someone's private or personal information without permission.
* Any other behavior that creates an unsafe, hostile, or unwelcoming environment.

## Reporting Issues

If you experience or witness inappropriate behavior, please report it to the repository maintainer.

You can report an issue through:

* A GitHub Issue, when appropriate and public discussion is suitable.
* A private message to the repository maintainer for sensitive or confidential matters.

When reporting an issue, please provide as much relevant information as possible so that it can be reviewed fairly and appropriately.

All reports will be taken seriously and handled respectfully.

## Enforcement

The repository maintainer reserves the right to take appropriate action when this Code of Conduct is violated.

Possible actions may include:

* A warning or request to change behavior.
* Removal of inappropriate comments or contributions.
* Temporary restriction from participating in the project.
* Permanent removal from the project or community in serious or repeated cases.

The goal of enforcement is to maintain a respectful, productive, and welcoming environment for everyone.

## Scope

This Code of Conduct applies to all project-related interactions, including GitHub Issues, Pull Requests, discussions, code reviews, comments, and other project communication channels.

## Acknowledgment

By participating in this project, you agree to follow this Code of Conduct and help maintain a positive and welcoming open-source community.
